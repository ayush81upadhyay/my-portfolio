# Ayush Upadhyay — Portfolio Website

A modern, animated personal portfolio website for **Ayush Upadhyay**, a Frontend Developer with 4+ years of experience in React.js, TypeScript, Next.js, Redux, Node.js, and Docker.

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Language:** TypeScript

## 📁 Project Structure

```
├── app/                  # Next.js App Router pages
├── components/           # Reusable UI components
│   ├── Hero.tsx
│   ├── About.tsx
│   ├── Experience.tsx
│   ├── Skills.tsx
│   ├── Education.tsx
│   └── Contact.tsx
├── public/               # Static assets
└── styles/               # Global styles
```

## ✨ Features

- Fully responsive design
- Smooth scroll animations powered by Framer Motion
- Interactive skill cards and timeline-based experience section
- Dark-themed modern UI with gradient accents
- Contact section with email and LinkedIn links

## 🏃 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
